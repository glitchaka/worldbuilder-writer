EL ARCHIVO NEO 0.2.0 — EDICIÓN PORTÁTIL PARA WINDOWS x64

REQUISITOS
- Windows 10 u 11 de 64 bits.
- Microsoft Edge instalado (incluido normalmente con Windows).

USO
1. Abre El-Archivo-Neo-Windows-x64.exe.
2. En el primer inicio, elige una carpeta externa para tus proyectos.
3. Crea una obra nueva o abre las que ya existan en esa carpeta.

ALMACENAMIENTO
- El ejecutable se distribuye sin proyectos ni novelas precargadas.
- Cada obra se guarda en su propia carpeta project-…
- project.json contiene el proyecto editable completo.
- Puedes respaldar, sincronizar o mover toda la carpeta de proyectos.
- Copiar el ejecutable a otra persona no copia tus historias.

FUNCIONES EN LÍNEA
- Spotify, YouTube y el corrector online necesitan conexión a internet.
- MP3, MP4 y OGG se reproducen desde el equipo; VOB depende de los códecs
  disponibles en Edge. La migración C# añadirá un motor nativo para VOB.
- La escritura, worldbuilding, tableros, mapas, maquetación, exportaciones
  y análisis local funcionan sin una cuenta del sitio web.

SEGURIDAD DE WINDOWS
Esta compilación no está firmada con un certificado comercial. Windows
SmartScreen puede mostrar “Editor desconocido”; usa “Más información” y
“Ejecutar de todas formas” si descargaste el archivo desde su fuente original.

DESINSTALACIÓN
La aplicación es portátil: basta con borrar el .exe. Tus proyectos externos
no se eliminan. La preferencia de carpeta queda en
%LOCALAPPDATA%\El Archivo Neo y puede borrarse por separado si quieres olvidar
la configuración local.
